# MicroHostname

Greenfield Micro Suite command-line utility.

## Install

```bash
pip install microhostname
```

## Run

```bash
microhostname
```

MIT

## Overview

Displays and explains system hostname information for educational networking purposes.

## Features

- Lightweight command-line interface
- Cross-platform Python
- Educational design
- Minimal dependencies
- Fast execution

## Educational Concepts

- Hostnames
- DNS naming
- Local identification
- Network naming conventions
